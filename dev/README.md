## Подъём тестовой DB

Нужен Docker. В корневой директории вводим команду:
```shell
docker-compose -f docker-compose.dev.yaml up
```
Поднимется контейнер с БД на порту `27017`. User: `root` Password `12345`. В директории `db/data` будут хранится данные из базы (это нужно чтобы при перезапуске контейнера сохранялись изменения, если эти изменения вам не нужны, удалите `db/data` и init данные зальются заново)
