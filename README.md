# Hackathon

## MongoDB

### Описание

MongoDB поднята в режиме ReplicaSet

Структура:

База данных состоит из трёх идентичных узлов. Каждый узел хранит все данные.
В начале работы выбирается основной узел, выполняющий все записи.
В случае если основной узел падает один из вторичных узлов берёт на себя статус основного.

### Ожидаемое поведение при подъёме

Поднимаем командой
``` shell
docker-compose -f docker.compose.dev.yaml up -d
```

По очереди поднимаются все три базы данных с healthcheck на предыдущую.
Если получаем error message: container <container_name> is unhealthy то у нас что-то упало у предыдущей базы, нужно лезть в её логи.

Далее если три базы по отдельности поднялись запускается контейнер mongo-init.
Он инициализирует реплика-сет скриптом scripts/replica-init.js.

Чтобы посмотреть логи - сразу после запуска пишем:
``` shell
docker logs mongo-init -f
```

В конце инициализации мы хотим получить Goida, это значит что ничего не сломалось.
